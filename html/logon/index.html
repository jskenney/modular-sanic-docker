Access Endpoints

Endpoints below require an API key. Send it as an Authorization: Bearer header and use - in the path, as shown, so the key stays out of URLs and logs (a key in place of - also works). With no header, - or session uses your web session. Add and remove must be sent as POST.

GET /auth/-/access/list/<user> (Authorization: Bearer <apikey>)
Lists Accesses (requires admin for other users)
POST /auth/-/access/add/<user>/<access>/<value> (Authorization: Bearer <apikey>)
Add/Modify Access (requires admin)
POST /auth/-/access/remove/<user>/<access>/<value> (Authorization: Bearer <apikey>)
Remove Access (requires admin)
